# Mídia kit do Investidor Matuto

Site estático independente para `midiakit.investidormatuto.com`.

## Configuração na Vercel

- Equipe: `germanomatutos-projects`.
- Criar um projeto separado: `investidor-matuto-midiakit`.
- Repositório: `GermanoMatuto/site-investidormatuto`.
- Root Directory: `midiakit`.
- Framework Preset: Other.
- Build Command e Install Command: sem comando.
- Output Directory: `.`.
- Production Branch: `main`, depois de integrar esta alteração.
- Adicionar `midiakit.investidormatuto.com` nos domínios do novo projeto.
- Se necessário, configurar exatamente o registro DNS indicado pela Vercel; não presumir o destino do CNAME.

A configuração da raiz e o projeto do site principal não são alterados.

O HTML contém o mídia kit com métricas consultadas em 15/10/2026, português/inglês/espanhol e contatos comerciais. A foto principal e as miniaturas usam URLs públicas das fontes. Verificar os três idiomas, os vídeos e os links de contato antes da publicação.
